# Lewis Heidrick

I build Home Assistant integrations and add-ons and network tools, and reverse engineer firmware and device protocols.

All projects: https://heidrickla.github.io

- [SSLReverseProxy](https://github.com/heidrickla/SSLReverseProxy): reverse proxy control plane with ACME certificates, mTLS, deny-by-default RBAC and an append-only audit log.
- [virtual-switches](https://github.com/heidrickla/virtual-switches): virtual Cisco Catalyst 9200, 9300 and 9400 switches with an IOS XE command line.
- [web-access](https://github.com/heidrickla/web-access): browser-based RDP; the client runs in the browser and the proxy never decodes the stream.
- [ha-cloudflared-connector](https://github.com/heidrickla/ha-cloudflared-connector): Home Assistant add-on running a Cloudflare Tunnel connector, with its own management panel.
- [tuxedo-touch-firmware](https://github.com/heidrickla/tuxedo-touch-firmware): custom firmware for the Honeywell Tuxedo Touch with a reproducible build.
- [iot-protocol-tools](https://github.com/heidrickla/iot-protocol-tools): tools for finding out how an IoT device talks to its cloud.
